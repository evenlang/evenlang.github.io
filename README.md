# Evenlang

Сайт Эвенской экспедиции — электронный портал о быстринском диалекте эвенского языка: [evenlang.ru](https://evenlang.ru/).

## Структура

- `_layouts` — общие шаблоны страниц;
- `_includes` — навигация, подвал, галерея и пагинация;
- `_posts` — новости экспедиции;
- `scientific` — основной раздел портала;
- `curious` — популярный раздел;
- `assets/css` и `assets/js` — стили и интерактивные элементы;
- `assets/gallery` — фотографии экспедиции;
- `static` — документы, аудиозаписи, шрифты и служебные изображения.

## Локальный запуск

```sh
bundle install
bundle exec jekyll serve
```

Собранный сайт появится в `_site`. Конфигурация публикации для AWS Amplify находится в `amplify.yml`.
